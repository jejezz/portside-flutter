## Features

- **Tabbed sessions** — open a tab per port and talk to several boards at once; background tabs keep receiving and logging
- **Hot-plug port list** — ports are rescanned every 2 seconds; any baud rate, with presets from 1200 to 230400
- **Real terminal** — ANSI 256-color and true-color, arrow keys and Ctrl combinations, scrollback up to 100,000 lines ([xterm2](https://pub.dev/packages/xterm2))
- **Line Sender** — write a script of commands, then press Enter to send the line under the cursor and move to the next; choose none / `\n` / `\r` / `\r\n` endings and local echo
- **Hex View and logging** — see the exact bytes received as a hex dump, and log raw bytes per tab to a file you choose
- **Terminal color schemes** — Solarized, Dracula, Nord, Gruvbox, green phosphor and more, with your font and size remembered
- **Light & dark, English & 한국어** — follows the system, or pick one in the toolbar

## Install

Download from [**Releases**](https://github.com/jejezz/portside-flutter/releases/latest):

| OS | File |
|---|---|
| macOS 12.0+ | `Portside-<version>-macos-universal.dmg` — open it and drag Portside to Applications |
| Windows 10/11 (x64) | `Portside-<version>-windows-x64-setup.exe` |
| Linux (x64) | `Portside-<version>-linux-x64.tar.gz` — extract and run `./install.sh` (`--remove` to uninstall) |

**Windows:** the installer isn't code-signed yet, so SmartScreen says "Windows protected your PC" — choose **More info → Run anyway**.

## How it works

Serial I/O goes through [libserialport](https://sigrok.org/wiki/Libserialport) (via `flutter_libserialport`), and the terminal is rendered by `xterm2`, which also handles keyboard input and escape sequences. Every received byte is also kept in a separate raw buffer, so Hex View and logs show exactly what the device sent — not what the terminal made of it.

### Keyboard shortcuts

| Action | macOS | Windows / Linux |
|---|---|---|
| New tab | ⌘T | Ctrl+Shift+T |
| Close tab | ⌘W | Ctrl+Shift+W |
| Start/stop logging | ⌘⇧R | Ctrl+Shift+R |
| Clear screen | ⌘K | Ctrl+Shift+K |

Windows and Linux add Shift because plain Ctrl+W/K/T are control characters the device's shell needs.

### Known limitations

- Typing Korean directly into the terminal breaks composition on macOS (an `xterm2` / `xterm.dart` text-input bug). The Line Sender box is a regular text field and isn't affected.

## Development

```bash
flutter pub get
flutter run -d macos
```

Build requirements:

- **macOS**: full Xcode (Command Line Tools alone aren't enough) and Homebrew `autoconf automake libtool pkg-config` — `flutter_libserialport` builds libserialport from source through CocoaPods
- **Windows**: Visual Studio with "Desktop development with C++"
- **Linux**: `clang cmake ninja-build pkg-config libgtk-3-dev liblzma-dev`

Design notes and history: [DESIGN.md](DESIGN.md). Building the Windows installer locally: [docs/windows-installer.md](docs/windows-installer.md).

Releasing: `scripts/bump-version.sh patch`, merge, then tag `vX.Y.Z` — CI builds and publishes every platform. Rules: [application-release-templates/conventions](https://github.com/jejezz/application-release-templates/tree/main/conventions).
